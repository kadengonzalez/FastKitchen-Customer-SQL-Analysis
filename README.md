# FastKitchen Customer SQL Analysis

## Overview
Analyzed a fictional fast-food restaurant dataset to understand customer behavior, spending patterns, and differences between registered and guest customers. This project focuses on SQL joins, aggregation, and data-driven insights commonly used in real-world analytics roles.

## Dataset
The dataset represents orders placed at a takeout-only fast-food restaurant and includes:
- Orders placed by registered users and guest customers
- Order totals, tips, and order types
- User location data (city, state, zip) for registered users

## Key Questions Answered
- What is the average amount spent per order?
- How do spending patterns differ by order type?
- Do guest or registered users place more orders?
- Which cities and zip codes have the highest customer activity?
- Which zip codes spend more on average than guest customers?

## Skills & Tools
- SQL (SELECT, WHERE, GROUP BY, ORDER BY, JOIN, LIMIT)
- LEFT JOIN for handling missing user data
- Aggregation with AVG, SUM, COUNT
- Data-driven reasoning and insight generation

## Key Insights
- Guest customers placed more orders than registered users
- Spending patterns were similar across order types
- Certain zip codes spent more on average than guest customers
- Customer distribution across multiple zip codes explained higher city totals
